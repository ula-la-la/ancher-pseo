# ancher.us publication contract

Apply this only after the corresponding Artifact has explicit approval and is public.

## Gallery page

- Keep the established Ancher visual language and existing page structure.
- Use the actual public Artifact screenshot as the finished-result image, not stock art or the X screenshot.
- Link the finished-result area to the public Ancher Artifact.
- Link the source trail directly to every original X post.
- The main Ancher CTA links to `https://app.ancher.ai`.
- Do not expose unpublished jobs in public navigation, audience pages, related items, sitemap, or route generation.

## Prompt and source section

- Put Prompt on the left and Source Trail on the right on the same horizontal line at desktop widths.
- Use balanced columns (`1fr 1fr`) and compact vertical spacing.
- Show only approximately 3–4 prompt lines initially; contain longer content with scrolling or a deliberate reveal.
- Keep the source card compact. Do not stretch either column to a tall neighbor or leave a large blank field below the shorter column.
- Stack cleanly on smaller screens.

## SEO and release checks

- The canonical route is `https://ancher.us/templates/<slug>`.
- Title, H1, meta description, Open Graph metadata, and structured data match the approved content and primary keyword.
- Add the page to sitemap and indexable routes only after approval.
- Confirm `robots.txt`, sitemap, Google indexability, GA4 page tracking, Artifact link, source links, responsive layout, and production response after deployment.
- Run lint, typecheck, tests, and the production build before requesting deployment approval.
